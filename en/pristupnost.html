Accessibility statement

We want everyone to be able to use our website comfortably – with a screen reader, with the keyboard only, or with enlarged text.

Compliance status

The website is partially compliant with WCAG 2.2 AA. According to our test of September 22, 2026, it meets every criterion that can be checked automatically. It has not yet been tested with a real screen reader or by users with disabilities, so we do not yet claim full compliance.

Standard we follow

We assess the website against the Web Content Accessibility Guidelines WCAG 2.2 at level AA and the European standard EN 301 549 (chapter 9 – web).

What the website meets

  • The whole site works with the keyboard alone, including the menu, the language switcher, the FAQ and the gallery. Each page starts with a “Skip to content” link.
  • The focused element is always visible, has a high-contrast outline and never hides under the top bar.
  • Text has a contrast of at least 4.5:1; large text and controls at least 3:1.
  • You can zoom the page to 200 % or narrow it to 320 px without horizontal scrolling. Nothing is cut off, even with wider line and letter spacing.
  • If reduced motion is switched on in your system, the website does not animate.
  • Images have text descriptions; screen readers skip decorative images.
  • Every language version declares its language, so screen readers use the right pronunciation.
  • The website has no time limits, never plays sound or video by itself and uses no tracking cookies.

Known limitations

  • The website has not yet been tested by screen reader users (NVDA, JAWS, VoiceOver). This test is in preparation.
  • The gameplay video is not on the website yet. When we publish it, it will have subtitles.
  • The legal texts are long and technical. If any part is unclear, we will gladly explain it by email.

How we test the website

Before publishing, we test every version of the website automatically in all nine languages in a real browser: keyboard navigation, contrast, zoom, text spacing, names of controls, headings and page language. We also review the results manually. Latest test: September 22, 2026.

Found a barrier?

Write to us at info@alexandersoft.net. Tell us which page and what the problem is, and if possible which browser and assistive technology you use. We will reply as soon as possible, within 30 days at the latest, and either fix the problem or provide the content to you in another way.

Enforcement

If you are not satisfied with our reply, you can contact the Czech Trade Inspection Authority (www.coi.cz).

This statement was prepared on September 16, 2026. We update it with every major change to the website.
