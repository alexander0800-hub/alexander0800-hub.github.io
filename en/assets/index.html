About these libraries

Each library is one Blender file with all textures packed, so there is nothing to relink. Every model is a marked asset with a preview, sorted into catalogs, with its origin on the ground and real-world scale in metres.

Materials use the standard glTF import setup (Principled BSDF with image textures), not procedural node networks. Licence: royalty-free use in personal and commercial projects; the files themselves may not be resold or shared (full text in the download).
