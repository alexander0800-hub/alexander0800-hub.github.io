Jak sprawdzić, czy plik jest nieuszkodzony

W systemie Windows otwórz PowerShell w folderze z pobranym plikiem i uruchom poniższe polecenie. Wynik musi zgadzać się z podaną sumą SHA-256. Jeśli się różni, nie uruchamiaj pliku i napisz do nas.

Get-FileHash .\clovicekhd-demo.exe -Algorithm SHA256

Ostrzeżenie Windows SmartScreen

Przy nowej aplikacji Windows może pokazać niebieskie okno „System Windows ochronił Twój komputer”. To normalne w przypadku programów, które nie mają jeszcze wielu pobrań.
