Как проверить, что файл не повреждён

В Windows откройте PowerShell в папке со скачанным файлом и выполните команду ниже. Результат должен совпасть с указанным SHA-256. Если он отличается, не запускайте файл и напишите нам.

Get-FileHash .\clovicekhd-demo.exe -Algorithm SHA256

Предупреждение Windows SmartScreen

Для новой программы Windows может показать синее окно «Система Windows защитила ваш компьютер». Это обычное дело для программ, у которых ещё мало загрузок. Нажмите Подробнее, затем Выполнить в любом случае. Наш установщик подписан сертификатом, поэтому в окне будет указано имя издателя.
